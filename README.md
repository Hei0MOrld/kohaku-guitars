# 琥珀guitars

群馬・富岡のギター/ベース修理・製作サイト。

## 公開手順（GitHub Pages）
1. このフォルダの中身を kohaku-guitars リポジトリに push
2. Settings > Pages > Source: main / (root) で保存
3. https://hei0morld.github.io/kohaku-guitars/ で公開

## 写真の入れ方
`images/` フォルダに写真を入れて、index.html の該当プレースホルダーを
<img src="images/ファイル名.jpg"> に差し替える。
差し替え場所は index.html 内のコメント <!-- PHOTO: ... --> を参照。

## 配布素材
